-- About --

Rock Paper Scissors is a Python game based on the classic hand game. This repository contains the game's Python source code.

Requirements:
- Python 3

How to Installation:
1. Download or clone this repository.
2. Open the project folder.
3. Run the revised version of the game:

```bash
python "rock paper scissors revised.py"
```

Source Files:

- `rock, paper, scissors.py` — Original game
- `rock paper scissors revised.py` — Revised version
